# Feature graphic style studies

Four visual-language studies for the same feature concept: “Reach More Buyers.”

- `option-a-editorial-geometric.png` — editorial geometric brand graphic
- `option-b-data-network.png` — precise data-network visualization
- `option-c-glass-layers.png` — translucent glass-layer system
- `option-d-sculptural-relief.png` — sculptural dimensional relief

Palette: sky blue `#4386DB`, soft blue `#78A7DC`, deep navy `#293043`, soft lime `#D3EE8A`, white, and pale blue-gray.

These are raster concept studies. The selected direction should be redrawn as SVG/CSS for production use.
